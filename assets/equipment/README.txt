Equipment photos go in THIS folder.
1. Save the photo here, e.g.  wheelchair.jpg   (letters, numbers, dot, dash, underscore only; no spaces)
2. In the app: Equipment > Edit item > 'Photo file name' > type  wheelchair.jpg > Save.
3. Upload/commit the folder to GitHub. Photos appear on the public page and in the admin.
Tips: JPG or WebP, about 600x600 px, under 150 KB each. File names are case-sensitive on GitHub (Wheelchair.jpg is not wheelchair.jpg).
One photo can be used by many items of the same type (e.g. all folding wheelchairs).
NEVER put photos of people here. This folder is public.
